本站是什么

这是王垠博客 yinwang.org 的免费阅读备份，不是作者的官方网站。每周抓取属于计划任务而不保证成功，失败时可能保留旧副本。排版、图片与代码可能与原文不同，Git 历史可保留旧修订；最新修订请以原站为准。本站不增加付费内容或广告。

数据从哪来

文章通过 yinwang.org 的公开 API 逐篇抓取，保存为自带图片的 Markdown；文件名、站点 URL 与图片目录三者一致，标题、作者、发布日期与原文链接记录在每篇文件的元数据里。同步由 GitHub Actions 每周一自动执行：只下载新增或有修改的文章，已有内容不会被覆盖改写。

被删除的文章如何保全

源站删除的文章不会从本站消失：由于每篇文件都进入 Git 历史，文章的所有历史修订（包括删除前的最后版本）都可在 GitHub 的提交历史中按文件名回溯查看。存档页在文章被移除后仍可阅读，并会在页首标注移除状态与 Git 历史入口——见已移除文章的阅读态示例。需要下架的版权方可直接邮件联系站长。

更正与反馈

发现排版问题、坏图或来源错误，请到 GitHub Issues 提交，附备份 URL、原文 URL 与简短说明。请勿在公开更正报告中提交私密内容或版权材料。

隐私

本站使用 Umami 做匿名的访问统计；搜索使用站点生成的本地索引，不向第三方发送你的输入。打开原文链接会离开本站。

许可

本站程序以 MIT 许可发布；归档文章与图片的版权归原作者所有。本站仅作备份存档，不销售任何内容，也不重新许可文章。
